04 — PRIVACY

Your money stays
your business.

[ LOCAL ONLY ]
  • No account.No sign-up, email address or bank login.
  • No server.Your transactions are stored on your phone. No analytics, trackers or ads.
  • Everything on the phone.Reading, parsing and categorising happen on-device. Message text and transaction data never leave it.
  • A small, explicit network boundary.An optional update check and exchange rates are the only network uses, with none of your data in the request. Tracking works offline.
  • Open to inspection.Source code is public. Check the APK checksums attached to a release before installing.

05 — INSTALL

A few taps.
Then let it listen.

Download APK ↗

Credu1ar is sideloaded, not on the Play Store. The button opens GitHub Releases; an APK is available once a release is published.

  1. Get the APK.

    Download from GitHub Releases, compare its checksum with the published checksum, and open it. Allow your browser or file manager to install unknown apps when Android asks.

  2. Unlock restricted settings.

    On Android 13+, sideloaded apps may need this before notification access can be enabled: Settings → Apps → Credu1ar → three-dot menu → Allow restricted settings. Wording can vary by phone.

  3. Allow SMS access.

    Open Credu1ar and grant SMS permission when prompted. It reads payment alerts and catches up on messages already in your inbox.

  4. Enable notification access.

    Follow the in-app link to Android’s notification access settings and enable Credu1ar. This adds Google Messages RCS and payment-app alerts. You can also explore with sample data first.

A FEW MORE SIGNALS

Good questions.

Is it always running?

No foreground service or permanent notification. Android wakes the app for incoming SMS and notification events. A catch-up scan on wake checks for missed SMS. Phone battery settings can affect capture; Diagnostics helps you check it.

What about Google Messages RCS?

RCS messages are not SMS, so they use the notification path. Enable notification access and let Google Messages show notification text. Hidden or truncated text can limit what Credu1ar can read.

Does it work offline?

Yes. Capturing messages, parsing, categorising and viewing spending all work offline. Update checks and exchange rates need a connection.

Which banks does it understand?

It uses bank-format rules and a generic fallback for financial messages. Coverage depends on the message format, not just the bank name. Financial messages it cannot confidently parse go to Needs review. There is no promise of support for every bank or alert.

Is it on the Play Store?

No. Credu1ar is a personal Android app distributed as a sideloaded APK through GitHub Releases.

Will a card-bill payment count twice?

Card-bill settlements, self transfers and investments are tagged as not spending and excluded from spend totals. The live demo includes a fictional card settlement so you can see the distinction.
