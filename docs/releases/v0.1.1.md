Credu1ar v0.1.1 is the **same app as v0.1.0** — no change to how it reads SMS, parses or shows your money. It exists so the download page tells you up front what to do about the Google Play Protect warning, which everyone installing an SMS-reading app from outside the Play Store will see.

## Install (read this if the install was blocked)

Credu1ar reads your payment SMS, so **Google Play Protect warns about it** — the same warning it shows for any sideloaded app that asks for SMS, because that permission is what SMS-stealing malware also asks for. It is your own app on your own phone, so you can allow it.

1. Download `Credu1ar-v0.1.1-android.apk` and open it (Files → Downloads → tap it).
2. When Play Protect blocks it:
   - If there is an **Install anyway** (under *More details*), tap it.
   - If the block only shows **OK** (India's stricter block for SMS apps): open **Play Store → profile picture → Play Protect → settings (gear) → turn off "Scan apps with Play Protect"**, install the APK, then turn the scan back **on**.
   - Or install over USB from a computer, which skips the block entirely: `adb install Credu1ar-v0.1.1-android.apk`.
3. After it installs, unlock the hidden SMS switch once: **Settings → Apps → Credu1ar → ⋮ → Allow restricted settings**, then grant **SMS** and turn on **Notification access**. The in-app **Arm it** screen links you to both.

Full step-by-step, with screenshots of where each toggle lives: [docs/INSTALL.md](https://github.com/Chiragjjjks/Credu1ar/blob/main/docs/INSTALL.md).

Verify the download against `SHA256SUMS.txt` on this page if you like.

## Measured (local release gate, Android 15 emulator `mn35`, JDK 17)

- Release APK: **1.34 MB** (1,403,872 bytes), R8-minified. (The published APK is built by CI and signed with a throwaway key — see *Known limits*.)
- Tests: **28** JVM tests, 0 failures (37 hand-written parser fixtures + 100 adversarial fixtures; `knownFailures` empty).
- Emulator smoke test: a real multi-part SMS PDU is stored, a UPI-app notification for the same payment de-duplicates against it (SMS kept), an OTP is dropped unread — **PASS**.
- Foreground memory is unchanged from v0.1.0 (~38 MB PSS with sample data); no app code changed in this release.

## Known limits

- INR only; foreign-currency card spends are listed as unreadable.
- Notification text can be truncated by the sending app; the SMS version wins when both exist.
- **Signing:** built by GitHub Actions without the project's signing secrets, so it is signed with a throwaway key. It installs and runs normally, but a release signed with a different key cannot install over it — you would uninstall first (export CSV, or re-import from SMS afterward). Setting the four CI signing secrets fixes this for future releases.
- A new release does **not** change the Play Protect warning; that is tied to the SMS permission and sideloading, not to the version.
