Credu1ar v0.1.2 fills itself in. The moment you let it read SMS, it reads your bank alerts for **this month**. In the **first week of a month** it also reads **all of last month**. No buttons, no "import 90 days".

## What's new

- **Automatic first read.** The read starts as soon as you link SMS, and you can watch it at the bottom of **Arm it**: `READING SMS · 1 OCT → TODAY · 412 / 1,050`, then `1 OCT → TODAY · 86 PAYMENTS FILED`.
  - Link on **1 November**: you get all of October plus today.
  - Link on **15 November**: you get 1–15 November.
  - The cut-off is day 7 (ADR-013).
- **Pulse opens where your numbers are.** Link on the 1st–3rd and it opens on last month. It now says `SPENT IN OCTOBER` and "You spent ₹6,750 in October" for past months. A finished month is compared with *all* of the month before it.
- **"Add September", one month at a time.** Older history is one tap per month, in **Arm it** or **System → SMS history**. Nothing older is read unless you ask.
- **A payment whose alert arrives late is filed under the right month.** For example, a payment on 31 Oct whose alert lands at 00:03 on 1 Nov goes under 31 Oct, not in November's window.
- **Delete everything means everything.** Deleted payments no longer come back from the inbox on the next open. New SMS are still filed.
- **Sample data is removed when real data arrives**, so fictional rows never mix into your totals.
- **Faster bulk reads.** Writes are committed once per 200 messages instead of 3–4 times per message. A live SMS arriving mid-read waits its turn instead of being starved.

## Install (and why Play Protect blocks it)

Play Protect in India blocks **every** app downloaded from a browser that asks to read SMS. No app change can lift that, and OTP auto-fill's trick can't read bank alerts. [docs/INSTALL.md](https://github.com/Chiragjjjks/Credu1ar/blob/main/docs/INSTALL.md) explains both.

- **Recommended:** install from a computer over USB or Wi-Fi: `scripts/phone-install.sh`. The block doesn't apply to adb installs.
- **Phone only:** Play Store → profile → Play Protect → gear → turn off *Scan apps with Play Protect*. Install, then turn it back on. Google does not promise this lifts the block.
- **Then:** if "Allow SMS" is greyed out, go to **Settings → Apps → Credu1ar → ⋮ → Allow restricted settings**.

Verify the download against `SHA256SUMS.txt` on this page if you like.

## Measured (local gate on this Mac, Android 15 emulator `mn35`, JDK 17)

- **Tests:** **35** JVM tests, 0 failures. New: 6 for the month window (owner's examples, day-7/8 edges, Feb/leap/year-end, a phone not set to IST) and 1 for whole-month comparison. Lint: 0 errors.
- **Emulator smoke test:** **PASS**. A real SMS is stored, a UPI-app notification de-duplicates against it, and an OTP is ignored.
- **First link on a seeded inbox:**
  - **Clock set to 2 Nov:** stored exactly the four payments since 1 Oct. Aug/Sep, the OTP and a personal chat were not stored. Pulse opened on October.
  - **Clock set to 15 Nov:** stored only November. The 31 Oct alert received 1 Nov was held back, then filed by **Add October**.
- **3,000-SMS inbox** (1,000 bank alerts, 2,000 offers/OTPs): first link took **≈12.6 s** including app start. 1,000 payments filed, 2,000 ignored, 0 unreadable. App memory right after: ~90 MB PSS.
- **Release APK:** **1.34 MB** (1,403,876 bytes local, R8-minified; the same size as v0.1.1 because of signing-block padding, checked to contain the new code). Private-key build signs as `CN=Credu1ar`; the published one is CI-built (see *Signing*).

## Known limits

- **RCS bank chats can't be read back.** Google Messages RCS chats are not in the SMS inbox. They are caught live once Notification access is on.
- **Signing:** this build is made by GitHub Actions without the project's signing secrets, so it uses a **throwaway key**. Every release so far has had a different key (v0.1.0 ≠ v0.1.1), and one will not install over another: uninstall first. Your SMS stay on the phone, so the new install reads this month back. The fix is for the owner to run `scripts/set-signing-secrets.sh` once. Builds installed with `scripts/phone-install.sh` use the private key and update in place.
- INR only. Notification text can be truncated by the sending app; the SMS version wins when both exist.
